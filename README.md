## Features

- Responsive layout for desktop and mobile
- A playful moving “No” button
- A “Yes” popup that says “Let's fix a date”

## Technology

The site uses plain HTML, CSS, and JavaScript and can be hosted as a static Vercel project.

Original concept adapted from [Funny-dating-website](https://github.com/Adityapatil0122/Funny-dating-website).
